# 0.3.0 release plan

Status: planned, 2026-11-07. A proposal, not a commitment; [ROADMAP.md](../ROADMAP.md) stays the source for what has shipped.

**Theme:** the Changes tree and the outline work the way a reviewer expects in a running IDE. 0.3.0 finishes the Changes tree work started after 0.2.0 and ships the outline and matching improvements already on main. It adds no new relationship kind; those go to [0.4.0](0.4.0-plan.md).

## Already on main

These are under `[Unreleased]` in [CHANGELOG.md](../../CHANGELOG.md):

- the outline's Hide and Minimise controls and the Structural Outline shortcut (#120);
- the SMART Diff viewer's own icon in the viewer switcher (#116);
- scored whole-file relationship matching ([relationships/03](../specs/relationships/03-relationship-matching.md), #95);
- a selected moved declaration's frames stay aligned while scrolling (#121);
- the fallback diff reads revisions off the UI thread (#122);
- summarized file rows and declaration rows open again from the Changes tree (#123).

## Release checks

- Every CI step passes: `./gradlew clean buildPlugin check` and `./gradlew verifyPlugin` on 2025.1 and the latest release, with no new internal, experimental or deprecated API use.
- Relationship matching changed, so [RELEASING.md](../RELEASING.md) step 3 requires the two-sided corpus validation and the merge validation. Their results go into a dated section of [VALIDATION.md](../VALIDATION.md), with every flagged file reviewed. The relationship benchmark runs with the `no-new-wrong-pairs` gate and is recorded. It becomes a release gate once [relationships/07](../specs/relationships/07-relationship-validation.md) is accepted.
- A manual check of the built plugin on IC 2025.1.3 and IU 2026.3 covers the two-sided outline, the merge outline, the Changes tree rows with the filter and caret follow, and double-click and Enter on summarized and plain rows. A check that a probe ran without the real click or key path is recorded as inconclusive, not as a pass.
- `pluginVersion=0.3.0`, the CHANGELOG section is dated, and the ROADMAP lists 0.3.0 as shipped. The maintainer publishes the `v0.3.0` GitHub release.

## Not in 0.3.0

- Rename grouping, inlining detection, the refactorings view and the relationship validation go to [0.4.0](0.4.0-plan.md).
- Summaries for added and deleted files and every other [Later](../ROADMAP.md#later) item.
